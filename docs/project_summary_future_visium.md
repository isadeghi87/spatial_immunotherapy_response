# Project Summary with Future Visium Data

**Spatial Biomarkers of Immunotherapy Response in Hepatocellular Carcinoma** is a reproducible multi-omics project designed to define why some HCC patients respond to anti-PD-1 / anti-PD-L1 therapy while others do not. The central resource is an integrated single-cell atlas of roughly 970,000 cells collected across five public HCC cohorts, with matched responder and non-responder labels where available. The repository harmonizes these studies into a shared analysis framework so that cell-state programs, immune composition shifts, and response-linked biomarkers can be evaluated consistently rather than cohort by cohort.

The current pipeline combines single-cell preprocessing, tumor microenvironment characterization, spatially aware biomarker discovery, bulk deconvolution, and downstream validation. Across the atlas, the strongest response-associated signals point to an immune-active but highly differentiated CD8 T-cell program: responders show higher cytotoxicity, activation, and late exhaustion signatures, while non-responders retain more progenitor-like CD8 states and unfavorable macrophage programs. These signals are not treated as isolated observations; they are integrated with ligand-receptor analysis, TCR dynamics, pathway scoring, CNV-aware immune evasion modeling, and external validation in bulk and trial-adjacent datasets.

A major strength of the project is that it already extends beyond dissociated single-cell data. The repository incorporates spatial transcriptomic context from HCC tissue profiling to identify tertiary lymphoid structure hubs, tumor-stroma gradients, and immune neighborhood patterns that cannot be recovered from cell suspensions alone. This spatial layer is important because immunotherapy response is shaped not only by which cells are present, but also by where they are located, how closely effector and suppressive populations interact, and whether immune programs concentrate at invasion margins or remain excluded from tumor cores.

Future Visium data will expand this spatial component from proof-of-concept analysis into a stronger translational validation layer. Additional Visium cohorts can be used to test whether response-associated CD8 exhaustion/cytotoxicity programs, macrophage polarity, TLS density, and ligand-receptor niches reproduce across independent specimens and treatment settings. With more Visium samples, the project can move toward patient-level spatial biomarkers, compare pre-treatment versus on-treatment tissue architecture, and quantify how immune topology changes across recurrence states or etiologic backgrounds such as viral versus NASH-associated HCC. These data will also improve spatial deconvolution and mapping of atlas-defined cell states onto intact tissue sections.

Overall, the project provides an end-to-end framework that links large-scale single-cell discovery to clinically interpretable spatial biomarkers. Including future Visium data strengthens the most distinctive goal of the repository: turning immune cell states into tissue-level biomarkers that can help explain, predict, and eventually guide immunotherapy response in HCC.
